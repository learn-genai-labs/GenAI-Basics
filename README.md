## GenAI Basics

### Summary:
    • LLM workflow: Input → Encoding (tokenization) → LLM prediction (self-attention) → Decoding → Output.
    • Types of models: LLM (text), LMM (multi-modal like Gemini), SLM (small models), VLM (vision-language).
    • Open vs Closed LLMs: Open-source (Ollama, Hugging Face) vs Closed frontier models (OpenAI, Anthropic, Grok, Gemini).
    • API keys for closed LLMs: Buy credits (e.g., OpenAI), create secret keys, use them to build agents, automations, micro SaaS.
    • GenAI tools ecosystem: Chat tools (ChatGPT, Claude, Gemini, Grok, etc.), AI code editors (Cursor, Replit, VS Code), Hugging Face for model sharing, Ollama for local model running.
 ### Key Takeaways
    • Understand LLM basics: Knowing how tokenization, self-attention, and decoding work is enough at this stage.
    • Explore open-source models: Platforms like Hugging Face and Ollama let you run models locally and study their capabilities.
    • Closed models need API keys: Access frontier models (OpenAI, Anthropic, Gemini) via paid API keys for advanced agent building.
    • Benchmarks matter: Always check model benchmarks and release notes to understand performance.
    • Tool categories are broad: From chat assistants to AI code editors and agentic coding platforms, knowing the ecosystem helps in practical applications.
